Discord Clone 💬

---

A simplified Discord-inspired chat application built with pure HTML, CSS and JavaScript.

🚀 Features
Multiple chat channels,
Dynamic message rendering,
Message editing and deletion,
LocalStorage persistence,
Dark/Light theme switch,
Image upload support,
Chat export system,
Automatic bot responses,
Responsive interface.

🛠️ Technologies Used
HTML5,
CSS3,
JavaScript,
LocalStorage API,
FileReader API,
DOM Manipulation,
